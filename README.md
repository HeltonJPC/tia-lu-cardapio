# Cardápio digital · Tia Lu

Site estático (HTML + imagens). Para publicar no GitHub Pages:

1. Crie um repositório (ex.: `tia-lu-cardapio`) e envie estes arquivos para a raiz.
2. No repositório: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. Em 1–2 minutos o site fica em `https://SEU-USUARIO.github.io/tia-lu-cardapio/`.
